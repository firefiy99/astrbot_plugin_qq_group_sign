# astrbot_plugin_qq_group_sign

每天在指定时间，为白名单内的 QQ 群执行群打卡。

> 创作者：**小星萤**  
> 版本：`1.1.2`  
> 支持平台：AstrBot `aiocqhttp` + NapCat

## 重要说明

本插件执行的是 **QQ 群打卡/群签到**，不是群成员发送 `/签到` 获得积分的功能。插件调用 NapCat 扩展动作：

- `set_group_sign`
- `send_group_sign`

这两个动作都只需要提供 `group_id`。QQ 官方机器人接口不提供此能力，因此本插件不支持 `qq_official`。

## 功能

- 每天按本机时间自动执行一次。
- 只有白名单内的 QQ 群会执行签到。
- 白名单为空时，为安全起见不会对任何群操作。
- 记录每个群最近执行时间、结果和错误信息。
- 签到成功后，同一天自动任务不会重复执行。
- 签到失败后，可在配置的时间窗口内每分钟重试。
- 提供管理员手动测试和状态查询指令。
- 状态文件保存在 AstrBot 官方插件数据目录，不会写入插件安装目录。

## 安装

将本目录安装为 AstrBot 插件，然后在 WebUI 中打开插件配置。插件没有额外的第三方 Python 依赖。

需要满足：

1. AstrBot 使用 `aiocqhttp` 适配器连接 QQ。
2. QQ 协议端为支持群打卡扩展接口的 NapCat。
3. 机器人账号已经加入白名单中的群。
4. 多 QQ 账号时，在配置中填写负责签到的 `platform_id`；单账号可留空。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否启用每天自动签到 |
| `platform_id` | 空 | 多 QQ 账号时指定负责签到的 aiocqhttp 平台 ID；留空使用第一个 |
| `sign_hour` | `8` | 执行小时，范围 0–23 |
| `sign_minute` | `0` | 执行分钟，范围 0–59 |
| `retry_window_minutes` | `10` | 失败重试窗口，范围 0–120 分钟 |
| `group_whitelist` | 空 | QQ 群号白名单；空表示不执行任何群 |

白名单支持英文逗号、中文逗号、分号、空格或换行。例如：

```text
123456789, 987654321
```

修改配置后，在 AstrBot WebUI 中重载插件。

## 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/群签到` | AstrBot 管理员 | 为指令所在的当前白名单群手动签到，并返回成功或失败结果 |
| `/群签到状态` | AstrBot 管理员 | 查看时间、白名单、客户端状态及今日结果 |
| `/立即群签到` | AstrBot 管理员 | 立即为全部白名单群执行一次，用于批量测试 |
| `/群签到帮助` | 所有人 | 显示插件帮助 |

指令别名：

- `/手动群签到`（`/群签到` 的别名）
- `/自动群签到状态`
- `/测试群签到`

## 执行规则

假设配置如下：

```text
sign_hour = 8
sign_minute = 0
retry_window_minutes = 10
```

插件会从每天 `08:00` 开始尝试签到。某个群签到失败时，会在 `08:00–08:10` 的定时检查中重试；成功后记录当天日期，不再自动重复执行。

手动执行 `/立即群签到` 不受当天成功记录限制，因此适合调试，但可能再次调用群打卡接口。

## 数据位置

运行状态保存在：

```text
data/plugin_data/astrbot_plugin_qq_group_sign/state.json
```

状态文件中只保存群号、执行时间和接口结果，不保存聊天内容。

## 常见问题

### 到时间没有执行

检查：

1. `enabled` 是否开启。
2. 白名单是否填写了正确群号。
3. AstrBot 所在设备的本地时间是否正确。
4. 多账号时 `platform_id` 是否对应负责签到的 aiocqhttp 平台。
5. 是否使用 `aiocqhttp` + NapCat，而不是 QQ 官方机器人。

### 提示“未找到可用客户端”

检查 aiocqhttp 平台是否已连接；多 QQ 账号时确认 `platform_id` 填写正确。单账号留空时，插件会自动选择第一个 aiocqhttp 平台。

### 返回权限不足或业务失败

确认机器人账号已加入目标群，并检查 NapCat 登录状态与版本。群打卡是 QQ/NapCat 扩展能力，接口可用性可能随 QQ 或 NapCat 版本变化。
